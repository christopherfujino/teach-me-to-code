Before the introduction of ES6 modules, JavaScript had a single global
namespace for all code in a single "application"[^1].

## Advantages of Modules

1. Encapsulation
1. Namespaces
1. Description of dependencies for conditional compilation

[^1]: This peculiar design decision was made when JavaScript applications
were just web pages, and the sum of the code executed was probably a form
validation check and maybe an animated mouse cursor.
